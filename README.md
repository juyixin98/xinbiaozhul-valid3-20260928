# 大规模折线段最近投影与里程定位服务

这是一个本地 C++20 后端工程。输入是一条折线段和若干二维查询点，输出最近投影点、候选段、段内参数、平方距离、累计里程及 BVH 剪枝计数。所有输入均为本地文本或合成夹具，不依赖外部账号和在线服务。

## 模块关系

- `src/geometry/`：有理数点、精确十进制解析、精确投影谓词、里程计算、独立全段扫描参考实现。
- `src/spatial/`：BVH 空间索引和精确包围盒平方距离下界。
- `src/service/`：配置、零长段策略、并列候选策略、服务编排、诊断记录。
- `src/io/`：批量 CSV 风格输入解析。
- `src/batch/`：命令行批处理入口。
- `src/tools/`：确定性合成夹具生成器。
- `tests/`：独立 CTest 可执行文件，使用自己的全段扫描参考，不通过核心索引生成答案。

## 关键语义

零长段默认保留。它的 `t=0`，投影点为重合端点，里程为该端点的累计里程；前一段结束里程与该零长段开始里程相同。配置 `zero_length_policy=reject` 时，工程返回明确类别 `ZERO_LENGTH_REJECTED_BY_CONFIGURATION`。

并列投影通过 `cpp_rational` 精确比较平方距离。所有最小平方距离相等的段都会返回，并按原始段号升序稳定排列。BVH 只有在“包围盒到查询点的精确平方距离严格大于当前最优平方距离”时剪枝；相等时不剪枝，因此不会丢失并列最优。

坐标和投影比较使用 Boost.Multiprecision 有理数；累计里程涉及平方根，使用 `cpp_dec_float_50` 输出。输入支持有限十进制和十进制指数，不使用浮点中间值解析坐标。

## 本地运行

依赖：

- C++20 编译器；本机验证目标为 g++ 13.3。
- CMake 3.20 以上；本机为 3.28.3。
- Boost 1.74 以上头文件；本机为 Boost 1.83。

构建、生成夹具并运行批处理：

```bash
./scripts/run_local.sh
```

也可以手动运行：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/generate_fixtures -o build/fixtures.csv --sawtooth-segments 2048
./build/nearest_projection_batch -i build/fixtures.csv -c config/default.properties -o build/results.csv
```

输入记录格式：

```text
V,x,y
Q,request_id,x,y
```

诊断写入 stderr，包含脱敏请求标识、接受/拒绝/无法判定、失败类别、候选数、访问节点、剪枝节点和原因；业务结果写入 stdout 或 `--output` 文件。

## 本地验证

测试命令：

```bash
./scripts/validate.sh
```

判断方式：每个测试均输出 `[PASS]`，CTest 返回 0。测试具体覆盖：

- 零长段里程和零长/普通段并列；
- 角点等距候选稳定集合；
- 端点投影落在相邻两段；
- 自交折线交点返回交叉段；
- 超出普通双精度安全整数范围的巨大坐标；
- 固定网格下 BVH 与独立全段扫描的候选集合和最优距离一致；
- BVH 确实发生剪枝，但剪枝后结果仍与全段扫描一致；
- 拒绝零长段时返回具体失败类别。

当前交付会话未执行测试套件；仅可如实以本地实际构建/测试输出为准。

## 算法假设

输入是单条有序折线段，段号由相邻顶点隐式定义。默认策略允许零长段。查询点为二维有限十进制。几何比较不依赖浮点；里程是欧氏长度累计，无理长度以 50 位十进制浮点输出。

BVH 是内存态、构建一次、批量查询复用的二叉树。它适合本工程的大规模本地批处理目标，但没有实现动态插入、持久化索引或网络 API。
