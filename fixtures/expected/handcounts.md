# Hand-computed derivation counts

These numbers were derived by hand and are the expected values asserted by the
test suite and `compare` CLI. They are NOT generated by the Earley kernel.

## Grammar `arith.bnf`

`E -> E '+' E | E '*' E | 'id'`

Let C(s) be the number of leftmost/parse-tree derivations of a token string
with k ids (k-1 operators). Every parse tree with k leaves and binary internal
nodes is counted by the Catalan-ish recurrence

  C(1) = 1
  C(k) = sum_{i=1..k-1} C(i) * C(k-i)

because each split picks a root operator position and the two subexpressions
are uniquely determined by their id counts (operators inside are fixed by the
string positions). This is the Catalan number C_{k-1}.

| string                         | ids | Catalan | count |
|--------------------------------|-----|---------|-------|
| `id`                           | 1   | C0      | 1     |
| `id + id + id`                 | 3   | C1      | 2     |
| `id + id * id`                 | 3   | C1      | 2     |
| `id + id * id + id`            | 4   | C2      | 5     |

Explicitly for `id + id * id + id` (4 ids, 3 operators) the five bracketings
are, marking the top-level split:

1. `(id + id * id) + id`
2. `(id + id) * id + id`  -> `((id + id) * id) + id`
3. `id + (id * id + id)`  -> `id + ((id * id) + id)`
4. `id + (id * (id + id))`
5. `(id + id) * (id + id)`

## Grammar `dup.bnf`

`S -> 'a' | 'a'` — the string `a` has exactly 2 derivations, one per
production. This verifies de-duplication does not merge distinct productions.

## Grammar `empty-chain.bnf`

`S -> A B; A -> epsilon; B -> C; C -> epsilon`. The empty string has exactly
1 derivation: S=>AB=>B=>C=>epsilon (unique rule at each step).

## Grammar `cyclic.bnf`

`S -> S | epsilon`. The empty string has infinitely many derivations:
`S=>epsilon`, `S=>S=>epsilon`, `S=>S=>S=>epsilon`, ... Recognition succeeds;
enumeration reports `infinite`, not a finite count.

## Grammars `leftrec.bnf`, `paren.bnf`, `binary.bnf`

These are unambiguous on their valid strings (exactly one leftmost
derivation), so every accepted input has count 1.
