# 设计说明

## 模块契约

`types.hpp` 定义跨模块数据结构。输入坐标是 `int64_t`，点 ID 是 `int64_t`，精确整数是 `cpp_int`，最终数值是 `cpp_dec_float_100`。模块之间传递角点时使用归一化分数 `Fraction`，避免浮点值回流到几何决策。

`predicates.hpp` 提供两类谓词：

- `exact_orientation`：精确 cross product，是凸包和几何结构的唯一依据。
- `near_collinear`：返回 cross、参考边长度平方、缩放残差和容差，仅用于诊断。

`hull.hpp` 返回显式 `HullKind`，调用者必须处理 `empty`、`point`、`segment` 和 `polygon`，不能靠除零异常推断退化。

`algorithm.hpp` 对原始点集计算最小面积矩形。它不直接接收凸包，是为了让所有原始点 ID（包括重复坐标）都能参与接触证据。

`batch.hpp` 拥有文本协议和 JSONL 错误契约。一个案例的异常会转换为一条错误记录，解析器随后继续处理后续案例；全局资源错误仍可在输出中按类别识别。

## 旋转卡壳

对于凸包边 `a -> b`，令：

```text
d = b - a
t(p) = (p - a) . d
s(p) = (p - a) . perp(d)
```

该方向外接矩形由 `min/max t` 与 `min/max s` 确定。面积为：

```text
(max_t - min_t) * (max_s - min_s) / |d|^2
```

多边形凸包的最小外接矩形至少有一条边平行于凸包边，因此逐条凸包边穷举即可。工程实现保留每次投影的极值和接触集合，日志足以直接重放候选方向。

## 包含与角点

角点：

```text
q = a + (t*d + s*perp(d)) / |d|^2
```

输出顺序为 `(min_t,min_s)`、`(max_t,min_s)`、`(max_t,max_s)`、`(min_t,max_s)`，在凸包逆时针、`perp(d)=(-dy,dx)` 的约定下为逆时针。

接触集合包括：

- side: `s == min_s`
- opposite: `s == max_s`
- begin: `t == min_t`
- end: `t == max_t`

角点接触是对应边接触集合的交集。线段退化为两个矩形角点共享端点 ID；点退化时四个角点共享全部重复点 ID。

## 独立测试参考

测试中的参考算法枚举所有点对方向，而不是调用 `convex_hull`。每个点对构造候选后：

1. 对所有点重算切向和法向投影。
2. 检查投影位于候选区间内，即矩形包含所有点。
3. 用独立分数面积排序。
4. 与被测算法选择的面积比较。

这不能替代形式证明，但能避免测试答案完全由被测凸包和同一组投影代码生成。
