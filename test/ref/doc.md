# 参考解析器（Reference Implementation）

`refparse` 包是一条**独立的 HTTP/1.1 请求解析路径**，仅供测试比对使用，
绝不出现在服务端构建里（目录位于 `test/`，主模块的非测试代码不导入它）。

独立性约束（防止“用同一段实现生成期望值”）：

1. **不导入 `h1parse/internal/protocol`**，错误类型、字符判定、状态机全部
   另写；
2. **算法不同**：生产解析器是流式状态机（边读边定帧、半包驱动），
   参考解析器要求调用方一次性给全一条请求的全部字节（含消息体），
   用“整体扫描 + 位置表”的方式解析，天然不存在缓冲复用问题；
3. **视角不同**：参考解析器从“一个完整字节串应当被如何解释”出发，
   生产解析器从“字节如何随时间到达”出发。差分测试把任意切分喂给
   生产解析器，把完整串喂给参考解析器，比较两者的请求序列/拒绝结论。

结果模型为三值，禁止把不确定结果说成成功：

- `Accept`：合法，给出方法、目标、定帧方式、**已消费字节数**；
- `Reject`：确定非法，给出拒绝发生时的字节下标与类别；
- `Truncated`：字节串未结束（还需要更多字节），不是成功也不是非法。
